# Лаборатория активов

Исследование управления активами из торгового бота ([project-trade-t-bot](../project-trade-t-bot), `research/stress_scenarios.py`, 26.11.2026) в виде библиотеки и сайта. Любую корзину активов можно прогнать через тот же анализ: дневной тренд бота, кризисные окна, сценарии гэпа на сегодняшних позициях, хвосты (EVT), контроль просадки с бутстрепом, режимы (HMM), распределение капитала вне выборки, Келли и значимость Шарпа.

Вторая часть — интеграция с [server-analytic-system](../server-analytic-system) (SAS), где строились портфели акций методами машинного обучения:

- дивиденды T-Invest и отчётность smart-lab из данных SAS дают полную доходность акций Мосбиржи и факторную лабораторию;
- портфели SAS проходят те же стресс-тесты, что и счёт бота;
- портфель из блоков складывает отбор акций, облигации, тренд бота и деньги по бюджету риска с пределом потерь в сценариях.

Исходный вопрос был такой: нужна модель, которая не предсказывает чёрных лебедей, а заранее говорит, что делать и как распределять капитал. Литература: Ang, «Asset Management: A Systematic Approach to Factor Investing»; Basile, Ferrari, «Asset Management and Institutional Investors». Формулы собраны на странице сайта «Теория».

## Запуск

```bash
uv venv .venv && uv pip install -e ".[dev]"     # или python -m venv .venv && .venv/bin/pip install -e ".[dev]"
cd web && npm install && npm run build && cd ..  # сайт собирается в web/dist
.venv/bin/ram serve                              # http://127.0.0.1:8000
```

Разработка фронта: `.venv/bin/ram serve` в одном терминале и `cd web && npm run dev` в другом (http://localhost:5173, `/api` проксируется на :8000).

Консоль:

- `ram study --preset main` — исследование корзины (пресеты: `main`, `main_guard`, `metals`, `energy`, `softs`, `forts_macro`, `world`, `us_indices`, `foreign_stocks`, `moex_shares`, `sas_max_sharpe`, `sas_min_risk`, `ruble`, `crypto`);
- `ram factors [--start 2015-01-01 --top 100 --cost 0.002]` — факторная лаборатория акций Мосбиржи;
- `ram ml` — ML-прогноз доходности акций; `ram valuation --date 2025-10-31` — оценка SAS на дату и сверка с его срезом;
- `ram book [--equity composite --bonds ofz --trend main --limit 0.25 --vol 0.10]` — портфель из блоков;
- `ram search золото` — найти актив;
- `ram fetch moex:cont:BR yahoo:GLD` — скачать ряды в кэш заново;
- `.venv/bin/python research/main_book.py [A B C D F G]` — стресс-тест бота по разделам, на данных этого репозитория;
- `.venv/bin/python -m pytest` — тесты.

Ссылка вида `http://127.0.0.1:8000/#/explore/rule?preset=crypto` сразу открывает и считает пресет.

## Активы

| Код | Откуда | Что |
|---|---|---|
| `yahoo:<тикер>` | Yahoo Finance | акции, фонды, индексы, валюты, крипта мира; цены с поправкой на дивиденды и сплиты |
| `moex:shares:<SECID>` | Мосбиржа ISS + SAS | акции и фонды на сегодняшнее число акций (сплиты ISS и консолидации до 2018 года по скачку цены); полная доходность с дивидендами T-Invest из данных SAS с 2019 года, раньше — ценовая |
| `moex:index:<SECID>` | Мосбиржа ISS | индексы (MCFTR, RGBITR — полной доходности) |
| `moex:currency:<SECID>` | Мосбиржа ISS | валютный рынок (CNYRUB_TOM …) |
| `moex:futures:<SECID>` | Мосбиржа ISS | один контракт, например вечный CNYRUBF |
| `moex:cont:<код актива>` | Мосбиржа ISS | склейка срочных фьючерсов FORTS (BR, GOLD, Si, RTS, SUGR …): переход за 7 дней до экспирации, доходность дня — внутри контракта предыдущего дня, как `futures_roll.stitch` бота |
| `cbr:<ISO>`, `cbr:RUONIA` | Банк России | официальный курс к рублю с 1998 года, RUONIA с 2010 года |

Ряды кэшируются в `data/cache/` (обновляются раз в 12 часов; если источник не ответил, берётся сохранённая копия). Первая загрузка ряда Мосбиржи занимает до минуты: ISS отдаёт историю страницами по 100 строк.

Данные SAS читаются из `../server-analytic-system/data` (или из папки в `RAM_SAS_DATA`): `tbank_dividends.csv` и `smartlab_financials.csv`. Без них акции — ценовая доходность, а в лаборатории только ценовые факторы. Состояние — `/api/sas`.

Доходность считается сверх стоимости удержания — это то, что зарабатывает лонг, профинансированный по ставке:

- `rub` — RUONIA (до 2010 года 8%, как в исследовании бота);
- `usd` — ставка T-bill;
- `rub-usd` — разница этих ставок;
- `none` — ставка не вычитается: фьючерс её уже содержит;
- поправка ставки, например −2,5% у юаня.

Выходные складываются в понедельник. Календарь — объединение торговых дней всех активов: в день, когда актив не торгуется, позиция просто держится.

## Портфель с заданными весами

Переключатель «портфель с весами» (`params.signal = "weights"`, вес — `AssetSpec.weight`) считает вместо правила тренда портфель:

- каждый день у актива его доля капитала;
- пока бумаги нет на бирже, её вес делится между остальными;
- эталон — те же бумаги поровну;
- кризисы, сценарии, хвосты, контроль просадки, режимы и распределение работают как для правила.

Пресеты `sas_max_sharpe` и `sas_min_risk` — портфели SAS на срезе 31.10.2025 (оценка по P/E, гибрид моделей). Состав выбран сегодня, поэтому прошлое — проверка на прочность, а не оценка доходности. С 2008 года сверх RUONIA:

| | В год | Шарп | Просадка |
|---|---|---|---|
| максимум Шарпа | +0,1% | 0,14 | 80% |
| минимум риска | +5,9% | 0,36 | 73% |
| те же 20 бумаг поровну | +2,3% | 0,22 | 79% |

До 2019 года доходность здесь без дивидендов.

## Факторы акций Мосбиржи

Страница «Факторы акций» (`/api/factors`, `ram factors`). Каждый месяц берутся `top` самых ликвидных бумаг основного режима TQBR на ту дату: недельные срезы ISS по датам с 2013 года, вместе с бумагами, позже ушедшими с биржи. По каждому из 13 факторов считаются:

- IC — ранговая корреляция с доходностью следующего месяца, и её t;
- доходности квинтилей, Q5 − Q1 и Q5 против всех с издержками оборота.

Дальше — регрессии Фамы–Макбета, корреляции факторов и порог Бонферрони на число проверенных факторов. Первый расчёт скачивает около 700 срезов (примерно 2 минуты), дальше — секунды.

Итоги 2015–2026, 100 бумаг, 0,2% за сторону, порог |t| > 2,89:

- **Ценовые факторы, 142 месяца.** Проходят моментум 12−1 (t = 3,8; Q5 − Q1 +13,7% в год) и низкая волатильность (t = 4,1, но разброс квинтилей мал). Доходность последнего месяца продолжается, а не разворачивается (t = −3,2), но оборот 77% в месяц съедает этот эффект.
- **Факторы по отчётам, 55–57 месяцев 2022–2026 годов.** FCF/P (t = 4,0), E/P (t = 3,6) и низкий долг (t = 3,0). Это коротко и только на бумагах, которые торгуются сегодня.
- **Фама–Макбет.** Вместе с остальными факторами E/P теряет значимость (t = −0,1). Устойчиво держится только продолжение последнего месяца (t = −4,0 по ценовым факторам и −3,0 по всем вместе); у моментума 12−1 t = 2,1 и 1,6.

## Оценка SAS на истории и ML-прогноз

**Оценка SAS на истории** (`valuation.py`; факторы `sas_*` на странице «Факторы акций»; `ram valuation --date 2025-10-31` — сверка). Конвейер справедливого мультипликатора SAS пересчитан на каждый конец месяца 2022–2026 годов (56 срезов) по отчётам, опубликованным до даты:

- база отрасли — эмпирический Байес;
- показатели отбираются пошагово: VIF ≤ 5, p ≤ 0,05 (HC3), ошибка вне выборки (LOO) снижается;
- модели — регрессия, дерево и нейросеть с внутренним подбором, кластеры по парному показателю, гибрид;
- каждую компанию оценивают модели, обученные без неё.

Сверка с собственным срезом SAS на 31.10.2025 — 115 общих компаний. P/E совпадает: ранговая корреляция 0,9997. Отклонения сходятся так: гибрид 0,95, регрессия 0,90, кластеры 0,96, нейросеть 0,89, дерево 0,83. Первый расчёт всех дат — около двух минут в 8 процессах, дальше берётся из кэша `data/cache/valuation-v1.json`.

**ML-прогноз** (`ml.py`, страница «ML-прогноз», `ram ml`):

- признаки — ранги факторов, цель — ранг доходности следующего месяца;
- обучение скользящее: прогноз на месяц делают модели, обученные только на прошлых месяцах; переобучение раз в 3 месяца;
- параметры заданы заранее;
- модели: сумма рангов без обучения, гребневая регрессия, градиентный бустинг, нейросеть;
- результат проверяется дефлированным Шарпом (Bailey, López de Prado) с поправкой на 33 испытанных варианта.

Итоги (100 бумаг, 0,2% за сторону):

- **Модели SAS объясняют мало.** Вне выборки модели P/E объясняют в среднем 8–12% разброса мультипликаторов. «Справедливый P/E» почти равен отраслевому, и отклонение SAS — в основном та же дешевизна. Все отклонения SAS имеют положительный IC (гибрид P/E t = 2,1, кластеры 2,9), но ни одно не проходит порог 3,05 на 22 факторах. Регрессия SAS Фамы–Макбета при E/P, B/P и S/P даёт гибриду t = 0,0.
- **ML на ценовых факторах, 2017–2026, 116 месяцев.** Лучший — бустинг: IC t = 6,8, +9,6% в год к рынку после издержек, DSR 0,85. У моментума в одиночку +8,1% и DSR 0,54, у суммы рангов −1,7% (знак «разворота» задан заранее неверно, модели находят его сами).
- **ML на всех факторах с оценкой SAS, 2023–2026, 43 месяца.** Один E/P даёт +11,1% и DSR 0,86, гребневая регрессия +12,3% и DSR 0,77, бустинг +6,9% и DSR 0,37.
- **Вывод.** Ни одна стратегия не дотягивает до уверенных 0,95. Сложность моделей не добавляет к простой дешевизне.

## Портфель из блоков

Страница «Портфель из блоков» (`book.py`, `/api/book`, `ram book`) собирает счёт из четырёх блоков на неделях панели TQBR:

- **акции** — верхняя пятая часть 100 самых ликвидных бумаг на каждый конец месяца:
  - по умолчанию — по среднему рангу моментума, низкой волатильности, E/P и FCF/P (отчётные факторы — с 2022 года);
  - или по прогнозу ML-бустинга;
  - или все 100 поровну, или индекс MCFTR;
- **облигации** — индекс ОФЗ RGBITR или корпоративных облигаций (RUCBITR до 2018 года, после налога; дальше RUCBTRNS);
- **тренд бота** — основной счёт (`main` или `main_guard`) на капитале в деньгах: RUONIA плюс доход правила;
- **деньги** — RUONIA.

Каждый конец месяца:

1. **Бюджет риска.** На 156 неделях доходностей сверх денег — ковариация Ледуа–Вольфа. Доли подбираются так, чтобы вклады в риск равнялись бюджету (задача Спину). Затем доли масштабируются к целевой волатильности без плеча, остаток — в деньги.
2. **Сценарный предел.** Сценарий — совместный ход юаня, золота в рублях, MCFTR и ОФЗ. Это гипотезы бота и кризисные окна, закончившиеся до даты. Блоки движутся с бетой к своему рынку (не меньше 1), тренд — по своим позициям на эту дату. Если сценарий забирает больше предела, квадратичная задача режет сильнее всего блок, который теряет больше всего на единицу своего бюджета. Хедж не режется.
3. **Недельная проверка.** Каждую неделю цель заново проверяется на позициях тренда этой недели. Счёт идёт к цели, если предел нарушен или блок отошёл от цели больше чем на 5 п. п. Всё пишется в журнал решений.

Итоги 2016–2026 (561 неделя, равный бюджет, цель 10%, предел 25%, отбор по четырём факторам, ОФЗ, основной счёт бота):

| | В год | Вол. | Шарп над RUONIA | Просадка | Худший сценарий |
|---|---|---|---|---|---|
| портфель из блоков | +14,0% | 5,7% | 0,51 | 11,6% | −25% |
| без предела | +17,0% | 7,2% | 0,79 | 13,9% | −124% |
| тренд «с защитой» | +15,3% | 5,4% | 0,75 | 10,0% | −25% |
| без тренда | +10,6% | 5,2% | −0,03 | 10,6% | −25% |
| 60/40 MCFTR и ОФЗ | +9,5% | 15,3% | −0,01 | 36,1% | −53% |
| деньги (RUONIA) | +10,9% | 0,7% | — | 0% | 0% |

- **Тренд — главный источник и доходности, и сценарного риска.** Разница Шарпа с вариантом без тренда +0,54 (t = 2,8), с 60/40 — +0,52 (t = 2,4). Но тренд держит ОФЗ с номиналом до двух капиталов блока, и «дефолт как в 1998-м» (ОФЗ −40% без выхода) забирает больше блока целиком. Поэтому предел режет в первую очередь его.
- **Предел стоит денег.** Шарп падает с 0,79 до 0,51 (t = −2,3). На этой истории не было ни дефолта, ни месяца закрытой биржи с обвалом облигаций, так что видна только цена страховки. На странице есть таблица «Цена предела»: от 15% до «без предела».
- **Отбор акций против индекса** +0,10 Шарпа (t = 1,1): блок акций в портфеле небольшой (около 20%), и разница тонет в шуме. Четыре фактора выбраны лабораторией на той же истории, так что это не полностью вне выборки.
- **Оборот блоков около 370% в год.** В основном это размер тренд-блока: позиции бота меняются, а с ними и потеря в сценарии.

## Перенос из бота и расхождения

- **Правило перенесено точно.** Если рядом лежит репозиторий бота, тест `test_same_as_the_bot_on_its_own_data` прогоняет обе реализации на данных бота. Они совпадают до 10⁻¹², в том числе со стопом 25% и контролем «с 10% до 35%».
- **Данные свои, и основной счёт выходит лучше:**

  | | Бот | Этот репозиторий |
  |---|---|---|
  | В год | +17,1% | +17,1% |
  | Шарп | 1,05 | 1,18 |
  | Просадка | 27,5% | 25,3% |

  Бот брал курс доллара до 2013 года у Yahoo (`RUB=X`). Этот ряд шумный: дневная корреляция с официальным курсом ЦБ за 2006–2012 годы всего 0,16, волатильность 13,6% против 10,6%. Здесь берутся курс ЦБ и юань ЦБ напрямую.
- **Выводы бота сохраняются:**
  - шорт юаня и золота ≤ 0,5: Шарп 1,18 → 1,28;
  - контроль «с 10% до 35%»: −0,9% в год, вероятность просадки больше 25% за три года 11% → 3%;
  - обе меры: Шарп 1,30 против 1,16 у правила со стопом.

  Отличие одно: на этих данных просадка не доходит до 25%, и стоп почти не срабатывает.
- **Издержки основного счёта.** Оборот около 115 номиналов в год, издержки 6,9% в год при 0,06% за сделку. В основном это ежедневное подрезание позиций под предел ГО: при спокойных ОФЗ полная позиция больше двух капиталов. Бот считает так же, просто раньше эта цифра нигде не выводилась.
- **Ближние фьючерсы Yahoo (`=F`)** около экспирации перескакивают между контрактами. У какао в 2024 году это ложные ходы по −20…−26%, у палладия +47% за день. На них тренд мягких товаров «терял» 12,6% в год. Сайт убирает явные выбросы и предупреждает об этом. Для сырья берите склейки FORTS (`moex:cont:*`) или фонды.

## Ограничения

- Это история и модель, а не прогноз. Подбор окна по таблице окон — перебор (раздел «Келли и Шарп»: лучший из 20 вариантов на трёх годах показывает Шарп около 1 без всякого преимущества).
- У сырьевых фьючерсов FORTS цены в долларах: доходность считается в долларовых пунктах, без курса рубля.
- Распределение капитала — только лонг и весь капитал в активах; правило тренда использует плечо, поэтому сравнивать их лучше по Шарпу и просадке, а не по доходу.
- Дивиденды и отчётность SAS — по сегодняшнему списку T-Invest. У ушедших с биржи бумаг их нет: факторы по отчётам и дивидендная доходность считаются только на выживших, а доходность таких бумаг ценовая. Ценовые факторы от этого не страдают.
